# Gabriel Vicent

**Desarrollador de software · Sistemas de gestión, APIs y aplicaciones web**

Construyo soluciones de software para operaciones comerciales: punto de venta, inventario, atención al cliente y procesos financieros. En mis proyectos trabajo con aplicaciones de escritorio, plataformas web y APIs.

**English:** I build business software for sales, inventory, customer support, and financial workflows across desktop apps, web platforms, and APIs.

## Proyectos destacados

- [**Balanzapro de escritorio**](https://github.com/gamijoam/BALANZAPROESCRITORIO) — POS para Windows con WPF, ASP.NET Core y PostgreSQL; reúne ventas, caja, inventario y módulos.
- [**InventarioArens**](https://github.com/gamijoam/inventarioarens) — API REST multiempresa para inventario y punto de venta, con Laravel y PostgreSQL.
- [**CRMARENS**](https://github.com/gamijoam/CRMARENS) — CRM multiempresa para centralizar conversaciones, contactos y leads; usa Next.js, NestJS, TypeScript, PostgreSQL y Redis.
- [**POS de escritorio**](https://github.com/gamijoam/escritorioinventario) — Aplicación de punto de venta para Windows con WPF, .NET y PostgreSQL.
- [**Invensoft**](https://github.com/gamijoam/inventario) — Plataforma SaaS multiempresa para distintos tipos de negocio, con FastAPI, React y PostgreSQL.
- [**TuFondo**](https://github.com/gamijoam/fatrans) — Plataforma financiera para el sector transporte, con Spring Boot y Next.js.
